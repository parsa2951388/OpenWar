About the project

Open War is an independently branded, community-maintained fork of an open-source real-time strategy project. It focuses on territorial expansion, alliances, multiplayer matches, and a tactical world-map interface. The source repository documents the codebase, releases, licensing, and development status.

Open War is an independent community project. It is not an official product of, or affiliated with, the upstream project's maintainers.
